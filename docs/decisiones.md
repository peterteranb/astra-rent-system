# Decisiones del equipo

Qué contiene: lo que decidió el equipo donde el cliente no dio una respuesta, cada decisión con su motivo y la respuesta del cliente con la que se relaciona; el código y los documentos las citan como D-xx.
Cuándo leerlo: cuando un documento cite una D, o cuando quieras saber por qué algo funciona así sin que el cliente lo haya pedido. Los IDs se explican en el [glosario de IDs](README.md#glosario-de-ids).

Palabras técnicas que aparecen en la tabla:

- **Migración:** archivo que crea o cambia las tablas de la base; Django lo genera desde `models.py`.
- **Bloquear la fila** (`select_for_update`): si dos personas guardan lo mismo a la vez, la segunda espera y ve lo que guardó la primera.
- **`on_commit`:** algo que se hace solo cuando la transacción se confirmó, por ejemplo mandar un correo.
- **Hilo:** un trabajo que corre en paralelo, para que la página no espere.
- **`PROTECT`:** la base no deja borrar una fila que otra tabla nombra.
- **CSRF:** una clave oculta en cada formulario que impide que otro sitio envíe formularios en nombre del usuario. **CORS:** el permiso que pide el navegador cuando una página llama a otro servidor.
- **waitress:** el servidor web de producción; **whitenoise:** sirve los estilos dentro de Django; **admin de Django:** la administración que trae Django en `/admin/`; **`date_hierarchy`:** la navegación por fechas de una lista del admin.

La columna «ENT» nombra la respuesta del cliente relacionada ([respuestas-del-cliente.md](respuestas-del-cliente.md)); «—» quiere decir que la decisión es técnica y no sale de una respuesta del cliente.
